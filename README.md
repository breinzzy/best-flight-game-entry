SKYLINE RUNNER — Island Hopper: a sunset flight game. Chase view over an island chain, the aircraft in frame with instruments lit, a runway ahead, altitude, speed and heading on the HUD. Thread 12 glowing target rings, then land on the runway before the timer runs out. Keyboard (arrows, Shift/Ctrl, P, M, R) and mouse; sounds are synthesised in the browser, no audio files, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
